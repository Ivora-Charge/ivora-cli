# Security policy

## Supported versions

The CLI is a pre-alpha scaffold and has no released version yet. Once releases begin, the
latest minor release receives security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately, not in a public issue:

- use GitHub private vulnerability reporting on this repository (Security tab, "Report a
  vulnerability"), or
- email the security contact: `<security contact to be added before the first release>`.

Include the CLI version (`ivora --version`), your operating system and the steps to
reproduce. Never include a real API key, station password or webhook secret in a report.

We aim to acknowledge a report within three working days.
